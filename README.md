# Toran

What's on at mandirs near you, and a simple seva rota for mandir committees.

This repo holds the Toran web app. The plan for how it is built lives in
`docs/`:

- `docs/architecture.md` — the technical plan: parts, data, checking events, privacy, v1 scope
- `docs/app-setup.md` — how the app is set up, from empty repo to live site
- `docs/decisions/` — records of hard-to-reverse decisions and why
- `docs/core-functions.md`, `docs/launch-plan.md`, `docs/market-gaps.md` — product
  scope, launch plan and market research, carried over from the research repo

Every change arrives through a pull request that passes the automatic checks.
