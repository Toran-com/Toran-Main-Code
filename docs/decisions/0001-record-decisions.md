# 0001. Record decisions in this folder

Date: 2026-10-07
Status: Accepted

## Context

Two people building part-time, often with Claude Code doing the typing.
Reasons for choices get lost in chats and calls.

## Decision

Every hard-to-reverse choice gets a short record here before it is built,
using `template.md`.

## Consequences

A few minutes per decision. In return, either of us (or a new helper) can
see why the system is the way it is, and Claude Code can read the same
reasoning.
