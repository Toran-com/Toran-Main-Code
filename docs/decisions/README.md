# Decision log

One short file per decision that would be hard to reverse. Write it before
building, so the reasoning is on record when someone asks "why did we do
it this way?" a year later.

## How to add one

Copy `template.md` to the next number (`0007-short-title.md`), fill it in,
and add it to the list below. Status is Proposed until both of us agree,
then Accepted. Never edit an accepted decision to change it; write a new one
that replaces it and mark the old one Superseded.
